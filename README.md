## About

This repository collects the laboratory work I produced for **CCCS 101 (Introduction to Computing)** in the BS Computer Science program at Camarines Sur Polytechnic Colleges (CSPC). Everything is written with plain HTML and CSS, with no frameworks, build tools or JavaScript.

The course final project, a multi-page website for CSPC student organizations, lives in its own repository: **`cspc-orgspace`**.

## Projects

### [HTML/CSS Activities](html-css-activities/)

**Laboratory activities** · 5 Nov – 29 Nov 2023

Four webpage exercises that build on each other, from a basic HTML page to a responsive recreation of the X landing page.

| # | Activity | Date | Skills practiced |
|:-:|---|---|---|
| 1 | [College of Computer Studies page](html-css-activities/lab_act1/) | 5 – 7 Nov | Headings, image, list, table, embedded CSS |
| 2 | [Sign-up form](html-css-activities/lab_act2/) | 15 Nov | Form inputs, external stylesheet, Flexbox, button states |
| 3 | [TikTok log-in page](html-css-activities/lab_act3/) | 20 – 21 Nov | Pixel-matched layout, icon buttons, hover transitions |
| 4 | [X landing page](html-css-activities/lab_act4/) | 28 – 29 Nov | Custom font, two-column layout, responsive breakpoint |

[**Read the full write-up →**](html-css-activities/README.md)

## Running the Projects

No installation or build step is needed. Clone or download the repository, then open the entry page of the activity you want in any browser:

| Project | Open |
|---|---|
| Activity 1 | `html-css-activities/lab_act1/WEBPAGE1.html` |
| Activity 2 | `html-css-activities/lab_act2/ORIAS_1A/WEBPAGE2.html` |
| Activity 3 | `html-css-activities/lab_act3/ORIAS_1A/WEBPAGE3.html` |
| Activity 4 | `html-css-activities/lab_act4/ORIAS_1A/WEBPAGE4.html` |

Some pages load fonts or icons online, so keep an internet connection on for them to display fully.
